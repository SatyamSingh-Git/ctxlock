# Dogfood: abandoned sessions and ablation, live

**Date:** 2026-11-21 · **Plan:** [Plan 10](../superpowers/plans/2026-11-21-ctxlock-loop-signals.md)

**Questions:**
- Does `misses` find the sessions that really were abandoned, and only those?
- Does `diagnose --ablate` tell something about a unit that the verdict and the fix's replay don't?

**Answers:** yes to both.
- **Abandoned sessions:** an independent scan found 2 abandoned sessions in all of the author's transcripts. `misses` found the one the collector recorded, at the same millisecond. The other came before the collector was installed.
- **Ablation:** on the planted miss, the fix validated, but taking the rule out changed nothing. So the rule wasn't what made the agent use npm.

## Ablation

**What was run:** `ctxlock diagnose rule/.claude/rules/deps.md F:/ctxlock-live/loop/repo --ablate`, with real Claude Code and Sonnet. The fixture is Plan 8's: a rule that says "Install packages with npm install", and a `package.json` that names pnpm.

```
Verdict: defect
  The file tells the agent to install packages with npm install, the agent followed it, and the person said the project uses pnpm.
…
Replay, 2 runs a side: validated
  miss-rule-.claude-rules-deps.md-4d49356f-99c06fe5  the miss  base 0/2  head 2/2  improved

Without the unit, 2 runs a side: unchanged
  miss-rule-.claude-rules-deps.md-4d49356f-99c06fe5  base 0/2  without 0/2  unchanged
Taking it out changes nothing: the unit does not drive the miss.

Runs: 9
```

It took 43 seconds.

**What it adds:**
- **The verdict's claim:** Claude said the file is wrong and the agent followed it.
- **What ablation found:** without the file, the agent still used npm in both runs, though `package.json` names pnpm. So npm is the agent's own default, and the rule's wrong line isn't what causes the miss.
- **What the fix does:** it validated because it says pnpm, which is what was missing. That makes this closer to a `gap` than a `defect`.
- **The fix holds either way:** the verdict alone could not have said which it was.

**The same run counted the planted session as abandoned too** ("1 correction, 1 abandoned"). It ends on the person's correction, which nothing answered, and it is days old. That is the rule doing what it says.

## What it doesn't show

- **Ablation of a skill** ran only against the stand-in Claude Code, in the tests.
- **"Found nothing" in a real diagnosis:** the planted session has no search in it, so the prompt's "found nothing" was checked in tests only.
